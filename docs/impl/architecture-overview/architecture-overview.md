# Architecture Overview

Stablecoin Stack consists of three main components:

1. Checkout Platform
2. Core Payment Processing Engine
3. Mobile Wallet (iOS & Android)

These components interact through signed payloads (EIP-712) and support ERC-2612 compliant tokens.
