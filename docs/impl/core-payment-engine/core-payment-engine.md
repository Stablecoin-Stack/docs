# Core Payment Engine

The Core Payment Engine handles the payment monitoring and settlement, and notifies the merchants:

The process relyes on

- EIP-712 signature validation
- ERC-2612 permit-based transfers
- Gas abstraction logic 
- Settlement verification

It ensures secure, replay-safe, and deterministic transaction execution with confirmation within seconds, in an enterprise-grade achitectured ssytem.
